📅 DOB Calculator – Minutes Lived App
📱 Overview

DOB Calculator is a simple Android application that allows users to select their Date of Birth (DOB) from a calendar and instantly calculates the total number of minutes they have lived.

It provides a fun and interactive way to see your life in minutes!

✨ Features

📆 Select Date of Birth using a Calendar Picker

⏱️ Calculates total minutes lived from DOB to current date

📊 Displays result instantly

🎨 Simple and user-friendly interface

⚡ Lightweight and fast performance

🛠️ How It Works

User selects their Date of Birth from the calendar.

The app converts the selected date into milliseconds.

It calculates the difference between the current time and the selected DOB.

The result is converted into minutes.

Total minutes lived are displayed on the screen.

🧮 Formula Used
Minutes Lived = (Current Time in Milliseconds - DOB in Milliseconds) / (1000 × 60)
🧑‍💻 Tech Stack

Language: Kotlin / Java

Platform: Android

IDE: Android Studio

UI Components: TextView, Button, DatePickerDialog
